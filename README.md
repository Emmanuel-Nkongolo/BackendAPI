Backend API with JWT (Node.js, Express, JWT, Prisma, Posgres
## How to use?
1. clone the repo
2. open the repo in your local computer
3. open it inside your code editor
4. open your terminal from inside the code editor
5. run *npm install*
6. run npm run dev

## Note: you need to have your database set as well to get it to work create an .env file and add DATABASE_URL variable in there and set it to the value of your database string connection and also a NODE_ENV and set it to either 'development' or 'production'
